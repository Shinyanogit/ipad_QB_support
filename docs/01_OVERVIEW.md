# Overview

QBオンラインとMM医師国試模試の復習ページに学習支援UIを注入する拡張。ChromeとSafari Web Extension（iOS/iPadOS）で共通コードベースを維持し、iPad上でも動作することを前提に設計する。

## 主な機能
- 設定パネル（ショートカット/表示/テーマ/プロンプト/テンプレート）
- 問題情報の抽出と表示（ID/進捗/選択肢数/タグ/掲載頁/画像）
- 解答後の振り返り欄（問題単位の自動保存、画像添付・再訪復元、将来のQB Anki生成用メタデータを保持）
- 右ドック型チャット（ストリーミング/Markdown表示/コピー/履歴、現在は一時停止）
- テンプレート送信（0-5件/ショートカット対応）
- Backend OAuth（Googleログイン）とFirestore設定同期
- バックエンド経由のOpenAI呼び出し（APIキー未設定でも利用可）
- 旧iframe UIと新しいトップ文書内UIの双方に対応するSPA/動的DOM追従

## 対象サイト
- `https://qb.medilink-study.com/*` (トップ)
- `https://input.medilink-study.com/*` (iframe)
- `https://moshi.medilink-study.com/kokushi/review/answer*` (MM医師国試模試の復習)
- `/result` の解答結果画面も問題ナビゲーション対象として扱う

問題ページは旧 `/Answer/...` と新 `/quiz?question_id=...` の双方を対象とする。

## 現在のマイルストーン
- QBページでコンテンツスクリプトが確実に注入される
- 右側ドックのチャットバーが開閉・リサイズできる（本文は押し出し）
- 問題文＋選択肢＋添付画像を自動で取り込んで質問応答できる
- モデル切替/説明レベル/共通プロンプトを設定から調整できる
- APIキー未設定でもバックエンド経由で `gpt-5-mini` / `gpt-4.1` が使える
- 解説末尾で振り返りを記録し、問題UUIDと `Vital_Step2CK` PDF指定を保存できる
- MM模試の復習画面でも、問題ナビ直前に同じ振り返り欄を表示できる
- MM模試でも `A`〜`G`、`S`、左右矢印の学習ショートカットを使える
- MM模試の問題・解説・解答履歴をダークテーマで一貫した配色にできる
